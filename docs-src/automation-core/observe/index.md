# **Observe Building Blocks**

[← Back to Automation Core](../index.md)

Observe focuses on delivering deep, real-time visibility into
application behavior, infrastructure performance, and network health
across hybrid and multi-cloud environments. It enables enterprises to
detect anomalies early, accelerate troubleshooting, and maintain service
reliability by transforming telemetry into actionable operational
intelligence.

## **Core Capabilities**

| Capability | Technology | Description |
|------------|-----------|-------------|
| **[Application Observability](application-observability.md)** | Instana | Automated, full-stack observability with granular visibility into applications, microservices, and infrastructure |
| **[Network Performance](network-performance.md)** | IBM SevOne | Comprehensive monitoring and analytics across complex network environments |

## **Github Repository**

Code for these accelerators can be found in the [Observe -- Automation

## **Use Cases**

### **[Application Observability (Instana)](application-observability.md)**
Organizations leverage this capability to gain real-time visibility into application
performance, automatically detect anomalies, trace transactions
across microservices, accelerate root cause analysis, monitor
Kubernetes / OpenShift workloads, and reduce mean time to resolution
(MTTR).

### **[Network Performance (IBM SevOne)](network-performance.md)**
Typical use cases include end-to-end network visibility, proactive detection of network
bottlenecks, traffic flow analysis, capacity planning, performance
trend analysis, SLA monitoring, and ensuring reliability across
distributed enterprise networks.
